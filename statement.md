## Troubleshooting Assistant   

##  Problem Statement

Many users face common technical issues in devices such as laptops, mobile phones, and internet connections. However, not everyone has the technical knowledge required to diagnose and resolve these problems. Most existing solutions require searching online, which may not always be reliable or easy to understand.

This project aims to provide a simple, offline solution that helps users identify problems and receive clear, practical suggestions without needing advanced technical skills.

---

##  Scope of the Project

The scope of this project is limited to handling common and frequently occurring issues in three main categories:

* Laptop-related problems
* Internet connectivity issues
* Mobile phone issues

The system uses predefined rules to provide solutions and does not involve machine learning or real-time diagnostics. It is designed as a basic assistant for guidance rather than a complete technical support system.

---

##  Target Users

This system is intended for:

* Students and beginners who are not familiar with technical troubleshooting
* General users who want quick solutions to common problems
* Anyone looking for a simple and offline troubleshooting guide

The system is designed to be easy to use, even for users with minimal technical background.

---

##  High-Level Features

* Menu-driven interface for easy navigation
* Multiple categories (Laptop, Internet, Mobile)
* Covers a variety of common issues in each category
* Provides possible causes and multiple solutions
* Simple and interactive command-line usage
* Works completely offline using Prolog

---

##  Project Approach

The system is built using a rule-based approach where each issue is associated with predefined causes and solutions. The user selects a problem, and the system responds based on logical rules defined in the program.
